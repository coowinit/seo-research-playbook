# 竞争网站研究检查表

用于网站级竞争研究完成后的快速自检。

## 研究范围

- [ ] 竞争网站与目标市场和产品真实相关。
- [ ] 没有因为品牌知名度高就自动把网站设为唯一标杆。
- [ ] 已记录研究日期。

## 证据边界

- [ ] 公开网站直接观察的事实有 URL 或明确来源。
- [ ] Ahrefs、Semrush、Similarweb 等数据已标记为第三方估算。
- [ ] 分析判断没有伪装成对方后台事实。
- [ ] `DR`、`DA`、`Authority Score` 等未被描述为 Google 官方排名分数。

## 网站结构

- [ ] 已记录主导航与重要二级入口。
- [ ] 已记录产品大类、系列和主要产品层级。
- [ ] 已识别产品页、指南页、比较页、工具页、资料页、案例页等页面类型。
- [ ] 已观察专业用户、经销商或承包商入口（如适用）。

## 搜索与内容

- [ ] 已研究代表性流量入口页面，而不是只看全站流量总数。
- [ ] 已按主题整理内容体系。
- [ ] 已判断内容如何支持产品和转化。
- [ ] 已识别竞争网站没有充分覆盖的用户需求。

## 内部链接

- [ ] 已观察导航、面包屑、正文、相关推荐与 CTA 链接。
- [ ] 已识别重要枢纽页。
- [ ] 没有把“内部链接越多越好”当成结论。

## 技术基础

- [ ] 已进行抓取、索引、Canonical、Sitemap、渲染和性能的高层观察。
- [ ] 没有仅凭 Lighthouse 或单个性能分数判断 SEO 强弱。

## 外链与品牌

- [ ] 已观察被链接最多的页面类型。
- [ ] 已区分品牌媒体曝光、渠道链接、行业引用与普通目录链接。
- [ ] 没有把竞争外链研究变成“照着购买链接”。
- [ ] 已识别品牌知名度、渠道网络等不可直接复制因素。

## 最终结论

- [ ] 已列出必须补齐的基础能力。
- [ ] 已列出可形成差异化的机会。
- [ ] 已列出值得保留的自身优势。
- [ ] 已列出当前阶段不值得复制的功能或策略。
- [ ] 研究结论可以转化为页面、内容、技术或业务动作。
