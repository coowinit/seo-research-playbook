# 技术 SEO 检查表

本检查表用于快速确认网站或重要页面是否存在抓取、索引、规范网址、状态码、渲染、结构化数据和性能方面的明显问题。

它不是“问题数量评分表”。发现问题后，应结合影响范围和业务重要性使用 [技术 SEO 审计与修复模板](../../templates/05-optimization/technical-seo.md) 记录。

## 1. 可访问与抓取

- [ ] 重要页面无需登录即可正常访问
- [ ] Googlebot 没有被错误阻止
- [ ] `robots.txt` 可正常访问
- [ ] `robots.txt` 没有误封产品、分类、文章等重要目录
- [ ] 重要 CSS / JavaScript 资源没有被错误阻止
- [ ] 重要页面可通过正常内部链接发现
- [ ] 私密资料使用权限 / 登录，而不是只依赖 `robots.txt`

## 2. 索引控制

- [ ] 希望进入搜索结果的重要页面没有误设 `noindex`
- [ ] 不希望索引的页面有明确、合理的控制方式
- [ ] `noindex` 页面没有因为 robots.txt 阻止而导致指令无法读取
- [ ] PDF / 文件的索引需求已按需考虑 `X-Robots-Tag`
- [ ] 测试 / 预览环境没有意外进入搜索索引

## 3. Canonical

- [ ] 重要独立页面 Canonical 指向预期规范网址
- [ ] Canonical 没有指向 404、重定向或无关页面
- [ ] 内部链接尽量直接使用规范网址
- [ ] Sitemap 使用规范网址
- [ ] HTTP / HTTPS、www / 非 www 等站点版本保持一致
- [ ] 参数与重复页面没有制造明显规范化冲突
- [ ] 语言版本没有被错误 Canonical 到其他语言页面

## 4. Sitemap

- [ ] Sitemap 可访问
- [ ] 已在 Search Console 提交或可被正常发现
- [ ] 主要规范网址已包含
- [ ] 没有大量 `noindex` 页面
- [ ] 没有大量 404 / 410
- [ ] 没有大量永久重定向网址
- [ ] 大型站点已按需拆分 Sitemap

## 5. HTTP 状态码与重定向

- [ ] 正常页面返回预期 `200`
- [ ] 永久迁移使用合理永久重定向
- [ ] 临时变化没有被误设成永久迁移
- [ ] 不存在明显重定向循环
- [ ] 不存在大量长重定向链
- [ ] 删除且无替代的页面返回真实 `404` / `410`
- [ ] 不存在明显 Soft 404
- [ ] 服务器没有持续性 `5xx`
- [ ] 产品下架页面没有全部无差别重定向到首页

## 6. JavaScript 与渲染

- [ ] 渲染后主要正文仍然可见
- [ ] 重要内部链接为可抓取 `<a href>` 链接
- [ ] 关键 SEO 内容不依赖点击 / 滚动后才首次出现
- [ ] JavaScript 错误不会让页面成为空白或近空白
- [ ] SPA 不存在的路由不会全部返回 `200`
- [ ] Lazy Load 不阻止关键图片或正文被发现
- [ ] 重要资源没有被 robots.txt 阻止

## 7. 结构化数据

- [ ] Schema 与页面真实可见内容一致
- [ ] 没有虚构价格、库存、评论、评分、认证或产品属性
- [ ] 只使用与页面内容真正匹配的类型
- [ ] Google 支持的富媒体结果类型已通过 Rich Results Test
- [ ] 没有把“通过验证”理解为“保证展示富媒体结果”
- [ ] 结构化数据模板更新时已抽查真实页面

## 8. Core Web Vitals 与性能

- [ ] 已优先查看真实用户数据（有数据时）
- [ ] LCP 问题已定位主要内容元素
- [ ] INP 问题已定位主要交互 / 脚本
- [ ] CLS 没有明显图片、广告、Cookie 或动态组件位移
- [ ] 首屏图片和视频体积合理
- [ ] 图片明确尺寸并使用合理响应式策略
- [ ] 第三方脚本数量与业务价值相符
- [ ] 没有为了 Lighthouse 单次分数频繁大改稳定页面

## 9. 移动端

- [ ] 主要内容移动端不缺失
- [ ] 菜单和重要链接可正常访问
- [ ] 不依赖 Hover 才能访问关键内容
- [ ] 无严重横向滚动
- [ ] 弹窗 / Cookie / 聊天工具不长期遮挡内容
- [ ] 图片、表格和视频适配移动端

## 10. 技术改动风险

- [ ] 修改 robots / Canonical / 重定向前已记录原配置
- [ ] 全站模板修改先进行小范围测试
- [ ] 有明确回滚方案
- [ ] 上线后重新检查实际响应和渲染结果
- [ ] 使用 Search Console 继续验证
- [ ] 技术问题按严重程度、影响范围和业务重要性排序

## 最终状态

- [ ] 没有阻断重要页面抓取 / 索引的问题
- [ ] 规范网址信号基本一致
- [ ] 重要页面状态码正确
- [ ] 关键内容可正常渲染
- [ ] 结构化数据没有明显误导
- [ ] 性能没有明显阻断性问题
- [ ] 所有高风险技术改动已经验证

**状态：** 待检查 / 待修复 / 待验证 / 技术放行
