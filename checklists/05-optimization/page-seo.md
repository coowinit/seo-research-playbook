# 页面 SEO 发布前检查表

本检查表适用于产品分类页、产品详情页、制造商 / 供应商页、文章、安装指南和其他重要 SEO 页面。

它只检查页面层问题。Canonical、结构化数据、JavaScript SEO、Core Web Vitals 等详细技术实现参见 [技术 SEO](../../docs/05-optimization/technical-seo.md) 和 [技术 SEO 检查表](technical-seo.md)。

## 1. 页面职责

- [ ] 页面类型符合主要搜索意图
- [ ] 页面职责与关键词到页面映射一致
- [ ] 页面有明确主要任务
- [ ] 没有和现有页面承担相同主要职责
- [ ] 用户看完以后有合理下一步

## 2. SEO 标题

- [ ] 每个重要页面有独立 `<title>`
- [ ] 标题准确描述页面内容
- [ ] 核心主题表达自然
- [ ] 没有关键词堆砌
- [ ] 没有大量重复模板文字
- [ ] 品牌名称简洁
- [ ] 没有为了固定字符数牺牲可读性

## 3. Meta Description

- [ ] 准确概括页面
- [ ] 与 SEO 标题互补
- [ ] 对用户有真实信息价值
- [ ] 没有关键词列表式堆砌
- [ ] 重要页面尽量使用独立描述
- [ ] 没有把固定字符数当成硬性规则

## 4. H1-H6

- [ ] 页面有一个清晰、突出的主要标题
- [ ] 主要标题与页面实际主题一致
- [ ] `<title>` 与 H1 语义一致
- [ ] H2 / H3 按内容从属关系组织
- [ ] 没有为了关键词重复多个相似主标题
- [ ] 没有为了视觉样式滥用标题标签

## 5. 网址

- [ ] 网址简洁、稳定、可理解
- [ ] 使用描述性单词
- [ ] 单词优先用 `-` 分隔
- [ ] 大小写规则统一
- [ ] 没有无意义参数或长 ID
- [ ] 没有为了覆盖关键词写成超长网址
- [ ] 没有无必要年份
- [ ] 已有网址不会只为加入关键词而修改

## 6. 首屏与正文

- [ ] 用户能较快确认页面是否回答自己的问题
- [ ] 开头没有大量无价值铺垫
- [ ] 核心答案与重要条件较早出现
- [ ] 正文结构符合用户理解 / 决策顺序
- [ ] 没有关键词密度要求
- [ ] 没有要求每个标题包含关键词
- [ ] 没有为了 SEO 增加无价值段落

## 7. 图片

- [ ] 重要图片真正帮助理解产品或内容
- [ ] 重要产品图片尽量为真实图片或明确示意图
- [ ] 文件名具有描述性
- [ ] Alt 描述图片内容和作用
- [ ] Alt 没有堆叠关键词
- [ ] 纯装饰图片没有强行添加 SEO 文案
- [ ] 重要图片放在相关正文附近
- [ ] 需要被发现的重要图片不是只依赖 CSS 背景图
- [ ] 图片尺寸与文件体积合理

## 8. 内部链接

- [ ] 页面链接到真正相关的重要页面
- [ ] 网站其他相关页面也有机会链接回本页
- [ ] 重要链接使用正常 `<a href>`
- [ ] 没有设置机械内部链接数量
- [ ] 没有大量无意义链接
- [ ] 链接位置符合用户阅读路径

## 9. 锚文本

- [ ] 锚文本能够描述目标页面
- [ ] 锚文本简洁自然
- [ ] 没有大量 `Click here / Read more`
- [ ] 没有为了关键词使用生硬长锚文本
- [ ] 没有所有内部链接都使用完全相同精确关键词

## 10. 面包屑

- [ ] 面包屑与真实网站结构一致
- [ ] 上级目录可以正常访问
- [ ] 当前页面名称准确
- [ ] 没有为了 SEO 人为增加无意义层级

## 11. 转化

- [ ] CTA 符合用户当前搜索意图
- [ ] 主要下一步清晰
- [ ] 信息型页面没有过度销售
- [ ] B2B 页面提供合理的产品、规格、目录、样品或询价入口
- [ ] CTA 没有反复打断阅读
- [ ] 移动端转化入口正常

## 12. 页面级基础发布

- [ ] 页面状态码正常
- [ ] 页面允许索引
- [ ] Canonical 基础配置正确
- [ ] 移动端主要内容可正常阅读
- [ ] 页面主要链接没有失效
- [ ] 正式页面不存在明显模板占位内容
- [ ] 发布后可以通过 Search Console 检查

## 最终结论

- [ ] 页面职责正确
- [ ] 页面信息层级清晰
- [ ] 页面 SEO 没有机械优化
- [ ] 用户和搜索引擎都能理解页面主要内容
- [ ] 页面能够自然连接到网站下一步内容或转化

**状态：** 待修改 / 待审核 / 可发布
