# SEO 文章发布前检查表

本检查表用于正文完成后的最终放行。建议按照“事实 → 专业 → 内容 → 页面 SEO → 技术发布”的顺序检查，不建议先优化关键词再补事实。

|---|---|

| 审核日期 |  |

---

## 1. 搜索意图与页面职责

- [ ] 页面类型符合主要搜索意图
- [ ] 页面职责与关键词到页面映射一致
- [ ] 开头较快进入核心问题，没有大段无价值铺垫
- [ ] 标题承诺与正文一致
- [ ] 没有混入应由其他页面承担的主要主题
- [ ] 没有与网站现有页面形成明显关键词内耗

---

## 2. 事实与证据

- [ ] 所有重要结论均能追溯到来源或明确依据
- [ ] 企业事实来自最新版企业资料
- [ ] 数据注明市场、时间和比较范围
- [ ] 成本明确是材料成本还是项目总成本
- [ ] 质保没有被等同于实际使用寿命
- [ ] 产品性能说明了产品型号、结构或适用条件
- [ ] 测试结论没有超出测试方法和适用范围
- [ ] 认证没有被扩展成未验证的法规承诺
- [ ] 引用标准或法规时已核对版本和适用地区
- [ ] 所有“待确认”“待补资料”已解决或删除相关结论

---

## 3. 高风险表述

- [ ] 未无依据使用 `waterproof`
- [ ] 未无依据使用 `fireproof`
- [ ] 未无依据使用 `maintenance-free`
- [ ] 未无依据使用 `slip-proof`
- [ ] 未无依据使用 `scratch-proof`
- [ ] 未无依据使用 `fade-proof`
- [ ] 未无依据使用固定寿命承诺
- [ ] 环保声明有材料、认证、回收比例或生命周期依据
- [ ] “最佳”“最安全”“最耐用”等比较性结论有明确范围和依据
- [ ] 营销表达没有突破检测、认证、规格和质保边界

---

## 4. 专业审核

- [ ] 产品结构和规格由合适人员核验
- [ ] 安装参数由技术 / 安装人员核验
- [ ] 检测、认证和性能表述已核验
- [ ] 质保相关内容已核验
- [ ] 企业制造或服务能力已核验
- [ ] 项目案例事实已核验
- [ ] 对存在争议或条件差异的问题已采用限定表达

### 专业审核结论

- [ ] 通过
- [ ] 限定后通过
- [ ] 待补资料
- [ ] 删除相关内容

## 5. 内容结构与可读性

- [ ] 页面有一个清晰、突出的主要标题，通常使用 H1；没有多个同等突出的重复主标题
- [ ] H2 / H3 层级清晰
- [ ] 每个主要章节回答一个明确问题
- [ ] 没有重复章节或大量同义改写
- [ ] 文章结构符合用户理解和决策顺序
- [ ] 表格只用于真正适合比较的信息
- [ ] 有序列表只用于真正存在步骤的信息
- [ ] 长段落已经适当拆分
- [ ] 重要限制没有藏在不显眼的位置
- [ ] 结论与正文证据一致

---

## 6. 关键词与页面 SEO

详细页面级检查可继续使用 [页面 SEO 发布前检查表](../05-optimization/page-seo.md)。


- [ ] 页面主题在 SEO 标题、H1、网址和正文中保持清晰一致
- [ ] 相关关键词和用户问题根据语义自然出现
- [ ] 没有机械关键词密度或关键词堆砌
- [ ] SEO 标题准确、独立并具有点击价值
- [ ] Meta Description 准确反映页面内容
- [ ] 网址简洁、稳定且没有无必要年份
- [ ] 图片文件名和 Alt 具有描述性
- [ ] 页面正文没有为了 SEO 加入无价值内容

---

## 7. 内容可信度与 E-E-A-T 自检

- [ ] 包含真实项目、安装、测试、制造或专业经验中的至少一种
- [ ] 对重要结论解释了原因、条件和差异
- [ ] 作者或内容负责人明确
- [ ] 技术审核角色明确
- [ ] 重要外部结论优先引用原始或可靠来源
- [ ] 显示发布日期和必要的更新时间
- [ ] 明确说明产品限制或不适用场景
- [ ] 能区分事实、经验判断和营销表达
- [ ] 内容不是竞争页面的简单改写
- [ ] 读者能够理解重要结论从哪里来

---

## 8. AI 使用检查

- [ ] AI 只用于允许的研究整理、结构、写作或编辑环节
- [ ] AI 没有被当成产品事实来源
- [ ] AI 没有凭空生成测试数据、认证、价格、案例或客户评价
- [ ] AI 生成的关键事实均经过人工核验
- [ ] 重要内容能够追溯到人工资料或外部来源
- [ ] 如项目要求记录 AI 使用方式，相关信息已经保存

---

## 9. 图片与可访问性

- [ ] 图片真实，或明确标注为示意图
- [ ] 没有改变真实产品颜色、纹理或结构造成误导
- [ ] 图表数据可验证
- [ ] Alt 描述图片内容而不是堆关键词
- [ ] 图片已压缩并使用合适格式
- [ ] 移动端图片、表格和长网址可正常阅读

---

## 10. 内部链接与转化

- [ ] 链接核心产品或主要承接页面
- [ ] 必要时链接相关产品、解决方案或支持内容
- [ ] 内部链接真正帮助用户继续理解主题，不机械规定数量
- [ ] 锚文本能够描述目标页面
- [ ] 行动引导符合用户当前决策阶段
- [ ] 表单或转化路径不过度打断阅读
- [ ] 没有反复强行销售

---

## 11. 技术发布

> 本节只做快速放行；完整检查参见 [技术 SEO 检查表](../05-optimization/technical-seo.md)。


- [ ] 页面状态码正常
- [ ] 页面允许索引
- [ ] Canonical 正确
- [ ] 移动端布局正常
- [ ] Core Web Vitals 没有明显问题
- [ ] 结构化数据与页面实际内容一致
- [ ] 面包屑和导航正常
- [ ] XML Sitemap 已包含页面或能被正常发现
- [ ] Google Search Console 可以检查页面

---

## 12. 发布后计划

- [ ] 已安排首次抓取 / 索引检查
- [ ] 已安排展示、查询词和点击观察
- [ ] 已安排排名与点击率复盘
- [ ] 已安排内容与转化复盘
- [ ] 实际周期会根据网站规模、数据量和页面阶段调整
- [ ] 已记录负责人和下一次复查时间

---

## 最终放行

只有在以下条件全部满足时，才建议标记为“可发布”：

- [ ] 无关键事实缺口
- [ ] 无未解决的高风险表述
- [ ] 专业审核通过或限定后通过
- [ ] 页面 SEO 与技术发布条件正常
- [ ] 内容负责人确认可以代表企业公开发布

**最终状态：** 待修改 / 待资料 / 待审核 / 可发布
