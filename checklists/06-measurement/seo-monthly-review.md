# SEO 月度复盘检查表

用于每月完成 SEO 数据记录后进行快速复核。目标是确保数据口径稳定，并把结果、诊断和工作动作连接起来。

## 数据准备

- [ ] 本月主要数据已经完整，不使用明显未完成的最新日数据形成重大结论
- [ ] Search Console 资源和搜索类型正确
- [ ] 网站分析工具的 Organic Search 口径与上月一致
- [ ] SEO 询盘归因规则与上月一致
- [ ] A 类询盘定义没有临时改变
- [ ] 第三方关键词数据来自同一工具 / 同一市场口径
- [ ] 已记录网站改版、产品调整、市场事件或季节性因素

## 核心结果

- [ ] 已记录 GSC 展示
- [ ] 已记录 GSC 点击
- [ ] 已记录非品牌点击及占比
- [ ] 已记录自然搜索会话
- [ ] 已记录 SEO 询盘
- [ ] 已记录 A 类询盘
- [ ] 已检查询盘转化率
- [ ] 已检查 A 类询盘占比和 A 类询盘转化率

## 成本与效率

- [ ] SEO 投入定义明确，没有和广告花费混在一起
- [ ] 已计算 SEO 询盘成本
- [ ] 已计算 A 类询盘成本
- [ ] 分母为 0 时显示空白 / `—`，没有 `#DIV/0!`
- [ ] 已结合近 3 个月滚动成本判断，不只看单月

## SEO 排名资产

- [ ] 已统计固定目标关键词 Top3 / Top10
- [ ] 固定目标关键词库没有为了本月表现临时更换
- [ ] 如记录第三方 Top10 / Top20 / Top100，已明确为第三方估算
- [ ] 没有把第三方关键词数量当成 Google 官方真实关键词总量
- [ ] 已记录有搜索点击页面数

## 环比与同比

- [ ] 已观察 GSC 点击环比
- [ ] 已观察 GSC 点击同比
- [ ] 已观察 SEO 询盘环比 / 同比
- [ ] 已观察 A 类询盘环比 / 同比
- [ ] 已观察目标关键词 Top10 环比 / 同比
- [ ] 季节性明显时没有只根据环比做结论

## 页面组诊断

- [ ] 已按产品目录 / 内容目录 / 页面类型检查主要增长来源
- [ ] 已找出主要下降页面组
- [ ] 已判断增长是品牌需求还是非品牌搜索扩展
- [ ] 需要时已进入 Search Console 查询词 × 页面深度分析
- [ ] 没有因为某个关键词下降就把整个网站判定为 SEO 下降

## 工作记录

- [ ] 本月重要 SEO 动作已经登记
- [ ] 每个重大动作都记录了原因和预计目标
- [ ] 重要修改已记录修改前数据基线
- [ ] 已设置合理复查日期
- [ ] 已回看前几个月重大动作的实际结果
- [ ] 需要时已记录对应 Commit / Release / 网站版本

## 下月计划

- [ ] 已把“事实”和“判断”分开
- [ ] 下一步动作有明确页面 / 目录
- [ ] 下一步动作有负责人
- [ ] 下一步动作有验证指标
- [ ] 数据不足的问题明确标记为继续观察
- [ ] 没有为了证明工作量而批量新增、更新或删除页面

## 最终结论

- [ ] 本月 SEO 结果可以用 3—5 个事实概括
- [ ] 能回答“增长 / 下滑主要发生在哪里”
- [ ] 能回答“本月重要 SEO 工作是什么”
- [ ] 能回答“下一步为什么做这些动作”
- [ ] 数据、判断、动作和后续验证已经形成闭环
