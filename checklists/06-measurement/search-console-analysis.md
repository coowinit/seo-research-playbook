# Google Search Console 网站级分析检查表

用于月度、季度、改版后或重大 SEO 项目的快速复核。

## 分析准备

- [ ] 已确认正确的 Search Console 资源
- [ ] 已确认目标国家 / 地区和主要语言
- [ ] 已选择合适的当前周期和对比周期
- [ ] 季节性网站已考虑同比
- [ ] 已记录期间的网站改版、URL 迁移、内容更新等重大事件

## 数据边界

- [ ] 没有把查询表格当成完整搜索日志
- [ ] 已考虑匿名查询造成的明细缺失
- [ ] 已考虑表格 / 导出行数限制
- [ ] 已理解页面数据通常归到 Canonical URL
- [ ] 没有要求图表总数与页面表格逐行相加完全一致
- [ ] 没有使用最新初步数据做重大决策
- [ ] 已注意 Search Console 与其他系统的时区差异
- [ ] 遇到异常波动时已检查官方数据异常记录

## 全站趋势

- [ ] 已比较点击
- [ ] 已比较展示
- [ ] 已比较点击率
- [ ] 已观察平均排名但没有把它当固定排名
- [ ] 已使用周 / 月趋势确认长期变化

## 品牌 / 非品牌

- [ ] 可用时已拆分品牌与非品牌
- [ ] 没有把品牌需求增长直接当成非品牌 SEO 成果
- [ ] 已观察非品牌新增搜索需求

## 页面组 / 目录

- [ ] 已按网站架构拆分主要页面组
- [ ] 已找出主要增长目录
- [ ] 已找出主要下降目录
- [ ] 没有因为旧博客下降就误判整个网站下降

## 页面

- [ ] 已检查 Top 增长页面
- [ ] 已检查 Top 下降页面
- [ ] 高展示低点击页面已结合查询和排名判断
- [ ] 高流量低业务价值页面已检查搜索意图
- [ ] 重要下降页面已检查内容、竞争、内链和技术状态

## 查询词

- [ ] 已检查核心查询
- [ ] 已检查新增长 / 新出现查询
- [ ] 已检查高展示低点击查询
- [ ] 已检查商业价值较高的机会查询
- [ ] 已检查意图偏移查询
- [ ] 没有因为排名 8—20 就机械增加内容

## 查询词 × 页面

- [ ] 已检查重点查询对应哪些页面
- [ ] 没有把“一个查询多个页面”自动判定为关键词内耗
- [ ] 真正冲突时已判断合并、重构、内链或技术动作

## 国家 / 设备

- [ ] 已检查目标国家的趋势
- [ ] 已检查非目标市场异常增长
- [ ] 已检查 Mobile / Desktop 差异
- [ ] 设备差异已结合查询、排名和页面体验判断

## 内容与改版增量

- [ ] 新内容已和旧承接页一起比较
- [ ] 已判断主题组整体是否真正增长
- [ ] 改版前后已按全站、页面组和重点 URL 分层比较
- [ ] URL 迁移项目已复查重定向、Canonical、Sitemap 和内部链接

## 业务价值

- [ ] 已把 Search Console 与网站分析 / CRM 分开理解
- [ ] 已检查流量与产品页点击 / 下载 / 样品 / 询盘关系
- [ ] 已关注“流量少但商机质量高”的页面

## 输出

- [ ] 已写明事实
- [ ] 已写明判断及可信程度
- [ ] 已写明具体动作
- [ ] 已写明明确不做什么
- [ ] 已设定下次观察时间
- [ ] 数据不足时结论为“继续观察”
