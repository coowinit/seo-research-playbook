# 网站架构与内容体系检查表

> 用于新站规划、网站改版或重要产品体系重构。它检查网站级关系，不替代单页 SEO 和技术 SEO 检查表。

## 一、业务与范围

- [ ] 目标市场、语言和主要客户已明确。
- [ ] 核心产品和业务优先级已明确。
- [ ] 主要转化动作已明确。
- [ ] 架构不是单纯根据竞争网站复制。

## 二、页面职责

- [ ] 首页、产品、内容、资料、案例等页面类型已有明确职责。
- [ ] 重要页面有一个主要承接任务。
- [ ] 没有因为关键词细微变化建立大量重复页面。
- [ ] 产品页与指南页职责没有混淆。
- [ ] 技术资料与营销内容职责没有混淆。

## 三、产品体系

- [ ] 产品大类对应真实产品结构。
- [ ] 产品系列层级对用户选择有价值。
- [ ] 不存在只有一个薄弱页面的多余分类层。
- [ ] 产品大类可以连接到所有重要系列 / 单品。
- [ ] 停产、替代和历史产品有处理规则。

## 四、内容体系

- [ ] 内容中心不是简单等于 Blog。
- [ ] 比较、安装、维护、技术资料、FAQ 等按用户任务组织。
- [ ] 重要内容能够连接到产品或其他下一步。
- [ ] 已识别需要网站枢纽页的成熟主题。
- [ ] 没有为了“主题集群”制造空洞枢纽页。

## 五、导航

- [ ] 主导航表达最重要的业务入口。
- [ ] 核心产品无需依赖站内搜索才能找到。
- [ ] 主导航没有塞入所有文章和关键词。
- [ ] 二级导航帮助用户完成区域内浏览。
- [ ] 重要链接使用可抓取的正常链接形式。

## 六、URL

- [ ] URL 规则稳定、清晰、一致。
- [ ] URL 不为了表现层级而过度嵌套。
- [ ] 现有稳定 URL 不因“更 SEO”被随意修改。
- [ ] 参数、大小写和尾部斜杠规则已统一。
- [ ] 内部链接、Canonical 和 Sitemap 的规范 URL 方向一致。

## 七、面包屑

- [ ] 重要页面有合理的层级路径。
- [ ] 面包屑符合用户理解，而不是机械复制 URL。
- [ ] 产品和内容页面使用各自合理的路径。
- [ ] 页面调整时有同步更新机制。

## 八、内部链接

- [ ] 产品大类能够链接到重要产品页面。
- [ ] 内容可以链接到相关产品、资料和下一步。
- [ ] 产品页能够链接到安装、技术资料和 FAQ。
- [ ] 相关指南之间有真实主题关系链接。
- [ ] 重要页面拥有合理数量和来源的内部链接。
- [ ] 已检查孤立页面。

## 九、技术资料与文件

- [ ] PDF / CAD / BIM / 测试报告对应明确产品。
- [ ] 重要文件有版本和日期管理。
- [ ] 文件更新不会让旧内部链接长期失效。
- [ ] 必要时提供资料说明页，而不是只裸链 PDF。
- [ ] 是否允许文件本身索引已进入技术检查。

## 十、案例

- [ ] 案例与真实产品建立关系。
- [ ] 案例与真实应用 / 地区建立关系。
- [ ] 案例能够返回产品或解决方案。
- [ ] 项目数据和图片具有证据来源。

## 十一、分类与筛选

- [ ] 正式 SEO 分类与界面筛选已区分。
- [ ] 不会为每个筛选组合自动建立索引页。
- [ ] 空筛选组合和无结果页面已列入技术风险。
- [ ] 排序参数不会被误当成独立内容规划。

## 十二、分页与加载

- [ ] 大型列表是否需要分页已确定。
- [ ] 后续内容有可发现的网址 / 链接路径。
- [ ] 不依赖爬虫主动点击“加载更多”。
- [ ] 无限滚动方案已记录技术验证需求。

## 十三、转化路径

- [ ] 信息型页面有合理下一步。
- [ ] 产品型页面有样品 / 下载 / 询价等入口。
- [ ] 专业用户能够找到规格、测试、安装等资料。
- [ ] 不同页面类型没有机械使用相同 CTA。

## 十四、旧站改版

- [ ] 已导出现有 URL 清单。
- [ ] 已标记有流量、有外链、有转化的重要页面。
- [ ] 每个旧 URL 都有明确迁移动作。
- [ ] 没有大量旧 URL 无计划直接删除。
- [ ] 重定向、Canonical、Sitemap 和上线验证已进入技术计划。

## 十五、最终检查

- [ ] 关键词页面映射与网站结构一致。
- [ ] 竞争网站研究已转化为行动，而不是照抄栏目。
- [ ] 页面状态已标记为已有 / 新建 / 更新 / 合并 / 重构等。
- [ ] 高优先级页面有明确制作顺序。
- [ ] SEO、业务、产品和技术之间的待确认事项已经记录。
- [ ] 当前架构可以解释“用户从哪里进入、怎样继续、最终去哪里”。

**结果：** 通过 / 有条件通过 / 需要重构
