# 历史内容治理与内容资产维护检查表

## 1. 盘点范围

- [ ] 已明确全站还是某个目录 / 产品线
- [ ] 重要 URL 已进入资产清单
- [ ] 页面类型和页面组已分类
- [ ] 每个重要页面都有明确页面职责
- [ ] 已标记产品 / 技术资料当前状态

## 2. 数据与证据

- [ ] 已记录 Search Console 基线
- [ ] 已结合业务价值，而不是只看 SEO 流量
- [ ] 已检查重要外链 / 外部引用
- [ ] 已区分事实、数据和分析判断
- [ ] 没有仅根据单日波动决定重大动作

## 3. 内容准确性

- [ ] 产品规格仍然正确
- [ ] 测试 / 认证仍然有效
- [ ] Warranty / 安装 / 安全信息已核验
- [ ] 法规或标准没有过时表达
- [ ] 过期信息优先于普通 SEO 微调处理

## 4. 页面职责与重复

- [ ] 已检查相似页面是否真正承接同一意图
- [ ] 两个页面获得相同查询展示时，没有自动判断为内耗
- [ ] 重复页面已决定重新分工、更新、合并或重构
- [ ] 没有为了覆盖关键词变体保留大量重复 URL

## 5. 治理动作

- [ ] 保持页面无需为了“新鲜度”机械更新
- [ ] 更新页面有真实事实或需求变化依据
- [ ] 扩展内容仍属于原页面职责
- [ ] 合并页面已确定真实目标 URL
- [ ] 重构页面已确认页面类型或职责存在问题
- [ ] 移除页面已确认无用户、业务、历史或替代价值

## 6. 旧产品 / 历史资料

- [ ] 停产产品已判断是否存在真实替代产品
- [ ] 有售后 / 历史支持价值的旧产品没有误删
- [ ] 无替代价值的页面没有统一重定向首页
- [ ] 技术 PDF 已标记版本和有效状态
- [ ] 旧技术文件不会继续误导客户

## 7. 技术处理

- [ ] 永久替代页面使用合适的永久重定向
- [ ] 无替代的永久移除页面返回合理 404 / 410
- [ ] Canonical 只用于合适的重复 / 规范化场景
- [ ] noindex 使用目的明确
- [ ] Search Console Removals 没有被当成永久删除机制
- [ ] Sitemap 只保留当前希望搜索引擎处理的规范页面

## 8. 链接与迁移

- [ ] 所有重要内部链接直接更新到最终 URL
- [ ] 没有不必要的重定向链
- [ ] 面包屑和导航已同步
- [ ] 重要可控外部链接已尽量更新
- [ ] 合并页面的历史价值已尽量承接

## 9. 上线验证

- [ ] 旧 URL 状态正确
- [ ] 新 / 目标 URL 返回正常
- [ ] Canonical 正确
- [ ] Sitemap 正确
- [ ] 页面可抓取 / 可索引状态符合预期
- [ ] 关键内部链接正常

## 10. 后续复盘

- [ ] 已安排 Search Console 后续检查
- [ ] 已观察查询是否集中到正确页面
- [ ] 已观察页面组总体表现，而不只看单 URL
- [ ] 已记录修改日期、原因和负责人
- [ ] 已确定下一次内容资产盘点时间
