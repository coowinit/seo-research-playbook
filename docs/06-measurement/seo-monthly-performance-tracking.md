# SEO 月度数据跟踪与工作记录

SEO 数据记录的目标不是每个月堆积更多数字，而是持续回答三个问题：

1. **结果有没有改善？** 搜索可见度、自然流量、询盘和高质量询盘是否增长。
2. **变化发生在哪里？** 哪些产品、页面组、国家、设备或查询词推动增长 / 下滑。
3. **为什么发生变化？** 本月做过哪些 SEO 动作，它们之后是否产生真实效果。

因此，本模块把月度 SEO 管理拆成三层：**结果表、诊断表、行动表**。

---

## 1. 在整套 SEO 流程中的位置

```text
SEO 工作动作
↓
月度核心数据
↓
趋势变化
↓
页面组 / 查询 / 国家 / 设备诊断
↓
判断原因
↓
制定下一轮动作
↓
继续记录结果
↺
```

本模块负责长期工作记录；更深入的网站级查询词、页面、国家、设备分析参见 [Google Search Console 网站级数据分析](search-console-analysis.md)。单个页面发布后的跟踪参见 [单页发布后表现与维护](page-performance-and-maintenance.md)。

---

## 2. 先统一数据口径

长期跟踪最怕“同一个字段每个月含义不同”。正式记录前先固定数据源和公式。

| 指标 | 推荐口径 |
|---|---|
| GSC 展示 | Google Search Console 的 Web Search 展示 |
| GSC 点击 | Google Search Console 的 Web Search 点击 |
| 非品牌点击 | 按统一品牌词规则排除品牌查询后的点击 |
| 自然搜索会话 | 网站分析工具中的 Organic Search 会话 |
| SEO 询盘 | 按统一归因规则确认来自自然搜索的询盘 |
| A 类询盘 | 按企业内部固定标准定义的高质量询盘 |
| SEO 投入 | SEO 工具、内容、开发、外包等直接投入 |
| 目标关键词 Top10 | 固定目标关键词库中进入 Top10 的关键词数量 |
| 全站 Top10 / Top20 / Top100 | Ahrefs、Semrush 等第三方工具估算，仅作为趋势参考 |

注意：**GSC 点击不等于自然搜索会话。** 询盘转化率建议长期固定使用：

```text
SEO 询盘 ÷ 自然搜索会话
```

不要某个月用 GSC 点击做分母，另一个月又改用 GA4 会话。

## 3. 第一层：月度核心结果

建议每月固定记录以下指标。

### 搜索可见度

- GSC 展示
- GSC 点击
- GSC 点击率
- 非品牌点击
- 非品牌点击占比

### 网站自然流量

- 自然搜索会话
- 有搜索点击的页面数

### 业务结果

- SEO 询盘
- A 类询盘
- 询盘转化率
- A 类询盘占比
- A 类询盘转化率

### SEO 效率

- SEO 投入
- SEO 询盘成本
- A 类询盘成本
- 近 3 个月 SEO 询盘成本
- 近 3 个月 A 类询盘成本

### SEO 排名资产

- 目标关键词 Top3
- 目标关键词 Top10
- 全站 Top10 估算
- 全站 Top20 估算
- 全站 Top100 估算

### 工作产出

- 新增 SEO 页面
- 更新 SEO 页面
- 本月重要 SEO 动作

## 4. 为什么保留“A 类询盘”

SEO 的目标不是单纯增加表单数量。

可能出现：

```text
自然流量 ↑
SEO 询盘 ↑
A 类询盘 ↓
```

这说明流量和询盘数量增长，但业务质量下降。因此建议同时观察：

```text
SEO 询盘
+
A 类询盘
+
A 类询盘占比
+
A 类询盘转化率
```

A 类标准必须由企业自己定义，并长期保持一致，例如目标市场、采购数量、产品匹配度、项目阶段等。

---

## 5. SEO 成本不要只看单月

SEO 与广告不同，投入和结果经常跨月发生：

```text
1 月投入内容制作
↓
3 月开始获得稳定排名
↓
5 月持续产生询盘
```

所以除了单月：

```text
SEO 投入 ÷ SEO 询盘
```

还建议观察：

```text
近 3 个月 SEO 投入总额
÷
近 3 个月 SEO 询盘总数
```

A 类询盘成本同理。

如果分母为 0，应显示空白或 `—`，不要出现 `#DIV/0!`。

---

## 6. 目标关键词与第三方全站关键词分开

建议同时保留两套排名数据。

### 固定目标关键词库

由团队自己维护，例如：

```text
核心产品词
商业比较词
B2B 采购词
重点长尾词
```

长期统计：

- Top3
- Top10
- Top20（如需要）

这套数据适合判断核心战略关键词是否改善。

### 第三方全站关键词估算

例如 Ahrefs / Semrush 中：

- Top10
- Top20
- Top100

它适合观察网站整体搜索覆盖趋势，但属于第三方数据库估算，不应当作竞争网站或自己网站的“真实 Google 关键词总量”。

---

## 7. 第二层：页面组 / 目录诊断

月度总表告诉我们“发生了什么”，页面组分析负责回答“发生在哪里”。

建议按网站真实架构分组，例如：

```text
/products/composite-decking/
/products/wall-cladding/
/resources/comparisons/
/resources/installation/
/resources/technical/
/projects/
```

每个页面组记录：

- GSC 点击
- GSC 展示
- 点击率
- 自然搜索会话
- SEO 询盘
- A 类询盘
- 业务价值
- 趋势判断
- 主要问题
- 下一步动作

只有页面组出现明显异常时，再进入 Search Console 查询词 × 页面等深度分析。

---

## 8. 第三层：SEO 工作记录

数据如果没有和实际工作动作关联，半年后很难解释变化。

每一次重要动作至少记录：

| 字段 | 说明 |
|---|---|
| 日期 | 实际上线或完成日期 |
| 动作类型 | 新建 / 更新 / 合并 / 技术修复 / 页面 SEO 等 |
| 页面 / 目录 | 影响范围 |
| 具体动作 | 实际做了什么 |
| 原因 | 为什么做 |
| 预计目标 | 希望改善什么 |
| 数据基线 | 修改前的关键数据 |
| 复查日期 | 什么时候重新看 |
| 实际结果 | 后续发生了什么 |
| 状态 | 计划中 / 进行中 / 已完成 / 继续观察 |
| 版本 / Commit | 需要时与 Git 版本对应 |

这张表的价值在于把：

```text
做了什么
→
为什么做
→
什么时候做
→
后来怎样
```

连接起来。

## 9. 环比与同比怎样使用

建议核心关注：

- GSC 点击
- SEO 询盘
- A 类询盘
- 目标关键词 Top10

同时记录：

```text
环比（MoM）
同比（YoY）
```

对于有季节性的企业网站，同比通常比单月环比更有解释力。

不要因为某个月环比下降就立即进行大规模重写。

## 10. 推荐月度工作流程

### 月初：整理上月完整数据

1. 填写月度核心数据。
2. 确认数据来源和口径没有变化。
3. 更新本月重要 SEO 动作。

### 第二步：观察结果

重点看：

```text
GSC 点击
非品牌点击
自然搜索会话
SEO 询盘
A 类询盘
目标关键词 Top10
有搜索点击页面数
```

### 第三步：找到变化发生在哪里

进入页面组分析：

```text
产品
内容
技术资料
案例
国家
设备
```

### 第四步：需要时进入深度诊断

使用 [Google Search Console 网站级分析模板](../../templates/06-measurement/search-console-analysis.md)。

### 第五步：形成下一轮动作

记录：

```text
事实
↓
判断
↓
动作
↓
负责人
↓
复查日期
```

---

## 11. 不建议记录太多“看起来专业”的指标

如果一个指标长期不会改变决策，就没有必要放进月度总表。

例如不建议为了完整而每月堆积：

- 大量单关键词排名；
- 每篇文章字数；
- 固定关键词密度；
- 无法解释业务价值的第三方评分；
- 只为了报表好看而增加的指标。

月度总表应尽量稳定，复杂诊断进入专门分析表。

## 13. 最终原则

SEO 月度跟踪不是为了证明“每个月都在增长”，而是建立一个稳定的工作证据链：

```text
数据
↓
趋势
↓
问题
↓
判断
↓
动作
↓
结果
```

只有长期保持相同口径、记录关键动作并持续复盘，SEO 数据才真正具有管理价值。
