# 关键词研究与页面映射

本模块用于回答两个核心问题：

1. 用户围绕某个产品到底会搜索什么？
2. 这些搜索需求应该由网站中的哪些页面承接？

关键词研究的目标不是得到一张“词越多越好”的表，而是把真实搜索需求整理成可执行的网站页面规划。

---

## 1. 关键词研究的最终产物

完成本模块后，至少应得到四项结果：

- 一份经过整理的关键词总表
- 一组具有明确边界的关键词主题组
- 一份关键词优先级判断
- 一份“关键词主题组 → 页面类型 → 目标网址”的映射表

如果研究结束后仍然无法回答“这个词应该由哪个页面承接”，说明关键词研究还没有真正完成。

---

## 2. 标准流程

```text
确定市场与业务目标
↓
选择母关键词
↓
建立关键词原始池
↓
清洗、去重与标准化
↓
判断主搜索意图
↓
补充业务 / 使用意图
↓
关键词主题聚类
↓
补充真实数据
↓
判断商业价值与可实现性
↓
关键词优先级排序
↓
页面类型判断
↓
目标网址映射
↓
检查关键词内耗
↓
进入搜索结果与竞争内容研究
```

---

## 3. 第一步：确定市场、产品与目标

### 目标

先明确 SEO 要服务的市场、用户和业务结果，再开始找词。

### 需要确认

| 项目 | 需要回答的问题 |
|---|---|
| 目标市场 | 美国、英国、欧洲、澳大利亚还是其他市场？ |
| 语言 | 英文、德文、西班牙文还是其他语言？ |
| 主要用户 | 房主、经销商、承包商、建筑师、进口商还是其他角色？ |
| 核心产品 | 主营产品是什么？有哪些重要细分类型？ |
| 商业模式 | B2B、B2C，还是两者并存？ |
| 主要转化 | 询价、样品、目录下载、购买、联系经销商还是其他动作？ |
| 可验证优势 | 哪些产品、制造、测试、认证、项目或服务能力有真实证据支持？ |

### 阶段门

市场、语言、主要用户、核心产品和主要转化目标没有确定前，不进入正式关键词研究。

### 常见错误

- 同时面向所有国家，却忽略不同国家的搜索习惯和产品叫法。
- B2B 制造商网站大量追逐面向终端消费者的关键词，却没有供应商、OEM、项目采购等页面。
- 先写文章，再思考文章应该服务什么业务目标。

---

## 4. 第二步：选择母关键词

母关键词是关键词研究的起点，不是最终唯一目标词。

### 判断标准

一个合格的母关键词通常满足：

- 能准确代表核心产品或主题
- 目标市场中的用户确实会使用
- 可以自然向产品类型、应用、性能、对比、安装、采购等方向扩展
- Google 搜索结果中存在相对稳定的主题和页面类型

### 示例

以 `composite decking` 为例，它适合作为母关键词，因为可以继续扩展到：

```text
产品类型
应用场景
性能问题
材料对比
安装维护
价格成本
B2B采购
地区需求
```

但母关键词本身不等于博客文章主题。

如果搜索结果主要由产品分类页、品牌产品页和零售集合页组成，更合理的承接页面通常是核心产品分类页。

### 输出

- 1 个主要母关键词
- 3—10 个同义词、近义词或市场常用表达
- 初步页面类型判断

---

## 5. 第三步：建立关键词原始池

先广泛收集，再统一清洗。这个阶段不要过早删除关键词。

### 常用扩展维度

| 维度 | 示例结构 |
|---|---|
| 产品类型 | 核心词 + 类型 / 结构 / 材料 |
| 技术结构 | 核心词 + 工艺 / 配方 / 表面 / 结构 |
| 性能问题 | 核心词 + 防滑 / 褪色 / 温度 / 划痕 / 寿命 |
| 应用场景 | 核心词 + 泳池 / 阳台 / 屋顶 / 海边 / 商业项目 |
| 对比评估 | 核心词 + vs + 替代材料 |
| 安装施工 | 核心词 + installation / joist spacing / gap |
| 清洁维护 | how to clean / repair + 核心词 |
| 价格成本 | 核心词 + cost / price / cost per square foot |
| B2B采购 | 核心词 + manufacturer / supplier / wholesale / OEM |
| 地区需求 | 核心词 + 国家 / 地区 / 城市 |
| 问题表达 | is / does / can / how + 核心词 |
| 品牌与替代 | 品牌 + alternatives / comparison |

### 推荐数据来源

#### 搜索引擎侧

- Google 搜索建议
- “其他用户还问了”
- 相关搜索
- Google Keyword Planner
- Google Search Console

#### 竞争内容侧

- 竞争网站栏目和产品分类
- 竞争页面标题、H1 和目录结构
- FAQ 与帮助中心
- 产品筛选项和规格字段

#### 用户侧

- 销售询盘
- 客户邮件
- 售后问题
- 安装问题
- 经销商反馈
- Reddit、Quora、YouTube 评论等公开讨论

#### AI 辅助

AI 可以用于：

- 补充扩展维度
- 发现遗漏的表达方式
- 初步整理同义词
- 帮助归类原始词表

但 AI 生成的关键词不代表真实搜索需求，也不能代替搜索量、点击、排名或趋势数据。

### 输出

形成未经最终判断的“关键词原始池”。

---

## 6. 第四步：清洗、去重与标准化

原始词表不能直接进入优先级分析。

### 需要处理的情况

- 完全重复词
- 单复数变化
- 词序变化
- 拼写差异
- 明显同义表达
- 只有大小写差异的词
- 与业务完全无关的词
- 品牌词与通用词混在一起
- 不同国家叫法混在一起

### 示例

```text
composite decking vs wood
wood vs composite decking
is composite decking better than wood
```

这三个词不应该因为写法不同就直接规划成三篇文章。

应先保留为独立查询词，再在后续聚类中判断是否由同一页面承接。

### 注意

“清洗”不等于“删除所有相似词”。

不同表达仍然可以保留在关键词总表中，用于理解用户语言和后续正文表达，只是不一定需要独立页面。

---

## 7. 第五步：使用双层意图分类

关键词意图建议分成两层，避免把“信息型”“B2B采购型”“安装型”等不同维度混为一类。

### 第一层：主搜索意图

回答：**用户这次搜索，主要想完成什么行为？**

| 主搜索意图 | 用户主要目的 | 常见承接页面 |
|---|---|---|
| 信息型 | 学习、理解、解决问题 | 指南、知识文章、FAQ |
| 商业比较型 | 比较方案、评估产品 | 对比文章、选购指南、解决方案页 |
| 交易型 | 购买、询价、寻找产品 | 产品页、分类页、询价页 |
| 导航型 | 寻找特定品牌、网站或页面 | 品牌主页、登录页、指定产品页 |

### 第二层：业务 / 使用意图

回答：**用户围绕产品具体在解决哪类问题？**

可根据项目选择使用：

- 产品了解
- B2B 采购
- 价格与成本
- 产品比较
- 应用场景
- 安装施工
- 清洁维护
- 故障排查
- 规格与性能
- 认证与合规
- 地区供应
- 品牌研究

### 示例

`composite decking manufacturer`

```text
主搜索意图：交易型 / 商业比较型
业务意图：B2B采购
```

`does composite decking get hot`

```text
主搜索意图：信息型
业务意图：性能问题
```

`composite decking vs wood`

```text
主搜索意图：商业比较型
业务意图：产品比较
```

### 判断方法

不能只根据关键词字面判断。

至少检查：

- 目标国家的 Google 搜索结果
- 前 10 名主要页面类型
- 搜索结果中的产品、文章、论坛、视频、购物等组成
- 用户问题和相关搜索

### 可信程度

对意图判断增加：

- 高：搜索结果非常一致
- 中：存在两种主要意图
- 低：结果混杂或数据不足

低可信度关键词不要急于建立独立页面，应先进入更深入的搜索结果研究。

---

## 8. 第六步：关键词主题聚类

关键词聚类的目标是：

> 找出哪些查询可以由同一个页面完整解决。

不是单纯按词面相似程度分组。

### 建议的合并依据

满足越多，越适合合并：

1. 用户想解决同一个核心问题
2. 主搜索意图一致
3. 业务 / 使用意图一致或高度相关
4. Google 前 10 名结果重合度较高
5. 搜索结果主要页面类型一致
6. 一个页面可以自然覆盖这些问题而不显得主题分散

### 建议的拆分依据

出现以下情况时优先考虑拆分：

- 主搜索意图明显不同
- 页面类型明显不同
- 对应不同转化动作
- 一个子主题需要大量独立证据和说明
- 两个主题在搜索结果中几乎由不同页面排名
- 合并后页面会同时服务完全不同的人群

### 示例：适合合并

```text
composite decking vs wood
wood vs composite decking
is composite decking better than wood
```

可以先归入同一主题组：

```text
Composite Decking vs Wood
```

### 示例：不适合合并

```text
composite decking cost
composite decking manufacturer
composite decking installation
```

这三个主题分别对应成本研究、供应商采购和施工支持，页面职责不同。

### 聚类原则

关键词主题组的名称应代表“用户问题”或“页面主题”，而不是简单复制一个关键词。

---

## 9. 第七步：补充真实关键词数据

关键词数据用于帮助判断需求规模和优先级，但不是唯一决策依据。

### 建议字段

- 月均搜索量
- 点击成本
- 广告竞争程度
- 趋势变化
- Search Console 展示量
- Search Console 点击量
- 当前排名
- 已有页面
- 数据来源
- 数据日期

### 数据使用原则

1. 所有数字必须记录来源和日期。
2. 不同工具的数据口径可能不同，不直接当成绝对事实比较。
3. 没有可靠数据时留空，不使用 AI 猜测。
4. 搜索量为 0 或很低，不等于没有商业价值。
5. B2B 长尾词可能搜索量很小，但单个询盘价值很高。
6. Search Console 已有真实曝光数据时，应优先参考自身网站数据。

---

## 10. 第八步：判断关键词价值

建议从多个维度判断，而不是只看搜索量。

### 默认参考维度

| 维度 | 判断问题 |
|---|---|
| 产品相关性 | 与主营产品是否直接相关？ |
| 商业价值 | 是否可能带来询价、样品、销售或项目机会？ |
| 搜索需求 | 是否存在稳定或增长中的搜索需求？ |
| 可实现性 | 当前网站是否有机会建立有竞争力的页面？ |
| 专业优势 | 企业是否拥有竞争对手难以复制的知识、数据或案例？ |
| 页面支持 | 是否能支持核心产品页、解决方案页或转化路径？ |

### 评分建议

可以使用 1—5 分进行快速判断，再按项目需要设置权重。

例如：

```text
产品相关性 25%
商业价值 25%
搜索需求 15%
可实现性 15%
专业优势 10%
核心页面支持 10%
```

这只是默认参考，不是固定 SEO 公式。

### 必须增加可信程度

总分之外，再记录：

```text
可信程度：高 / 中 / 低
```

例如：

- 有 Keyword Planner + Search Console + 明确搜索结果支持 → 高
- 只有第三方工具数据 → 中
- 主要来自经验或 AI 扩展 → 低

### 为什么需要可信程度

两个主题都得到 80 分，不代表它们的结论同样可靠。

优先级排序必须同时看：

```text
价值
+
数据可靠性
+
资源条件
```

---

## 11. 第九步：关键词到页面映射

关键词研究必须最终落到页面。

### 页面映射字段

| 字段 | 作用 |
|---|---|
| 主题组 | 当前需要解决的核心主题 |
| 主关键词 | 该主题最具代表性的关键词 |
| 主搜索意图 | 信息、比较、交易或导航 |
| 业务 / 使用意图 | 采购、安装、比较、应用等 |
| 页面类型 | 分类页、产品页、解决方案页、文章、指南等 |
| 目标网址 | 计划承接该主题的网址 |
| 页面状态 | 已有 / 新建 / 更新 / 合并 / 重构 |
| 主要行动引导 | 用户阅读后的下一步动作 |
| 优先级 | 高 / 中 / 低，或评分 |

### 示例

| 主题组 | 主关键词 | 主搜索意图 | 业务意图 | 页面类型 | 目标网址 | 行动引导 |
|---|---|---|---|---|---|---|
| Composite Decking 核心产品 | `composite decking` | 交易型 | 产品了解 | 产品分类页 | `/composite-decking/` | 查看产品 |
| 制造商与供应能力 | `composite decking manufacturer` | 交易 / 比较 | B2B采购 | 商业落地页 | `/composite-decking-manufacturer/` | 获取报价 |
| Composite Decking 与木材对比 | `composite decking vs wood` | 商业比较型 | 产品比较 | 对比文章 | `/blog/composite-decking-vs-wood/` | 查看产品 |
| 安装施工 | `composite decking installation` | 信息型 | 安装施工 | 安装指南 | `/guides/composite-decking-installation/` | 下载说明 |

### 一个重要原则

> 一个重要主题应有一个主要承接页面，但一个页面可以自然覆盖多个同义词、近义词和相关问题。

---

## 12. 第十步：检查关键词内耗

关键词内耗不是“两个页面出现了同一个词”，而是：

> 多个页面在争夺同一个核心搜索需求，却没有明确职责分工。

### 检查方法

针对每个高优先级主题，检查：

- 网站是否已经有相关页面？
- 是否有两个以上页面标题和主题高度相似？
- Search Console 是否显示多个网址轮流获得同一查询的展示？
- 新页面是否会与现有产品页、分类页或文章竞争？
- 是否应该更新旧页面，而不是新建页面？

### 常见处理方式

- 保留主页面，重写其他页面定位
- 合并内容
- 调整内部链接
- 调整标题和正文主题
- 设置重定向
- 新建更明确的子主题页面

不要仅因为关键词相似就删除页面，应先判断搜索意图和页面职责。

---

## 13. 页面状态的五种常用决策

关键词映射时不要只记录“新建”。

建议统一使用：

| 状态 | 含义 |
|---|---|
| 已有 | 页面存在且定位基本正确 |
| 新建 | 网站没有合适页面，需要新增 |
| 更新 | 页面存在，但内容质量或搜索需求覆盖不足 |
| 合并 | 多个页面应该整合为一个更强页面 |
| 重构 | 页面类型、意图或网址职责需要重新设计 |

这样关键词研究会直接进入网站维护，而不是只产生新文章任务。

---

## 14. 关键词优先级不是发布顺序的唯一依据

高分关键词不一定马上做。

最终排期还要考虑：

- 核心产品页是否已经准备好
- 是否有技术资料和图片
- 是否有真实证据支持
- 是否需要技术人员审核
- 是否存在更基础的上游页面
- 是否能形成合理内部链接
- 当前开发和内容资源

例如：

如果核心产品分类页都没有完善，不建议先发布大量围绕该产品的博客文章。

---

## 15. 推荐的第一批页面顺序

对于新的产品型网站，可以优先考虑：

```text
核心产品 / 分类页
↓
重要细分产品页
↓
B2B采购 / 制造能力页
↓
高价值比较与选型内容
↓
重要应用解决方案
↓
安装、维护与常见问题
↓
更细的长尾主题
```

这不是固定规则，但通常比“按搜索量从高到低写博客”更符合企业网站的结构建设逻辑。

---

## 16. 关键词研究完成标准

进入下一阶段前，至少确认：

- [ ] 目标市场、语言和主要用户已经明确
- [ ] 母关键词已经确定
- [ ] 已建立较完整的关键词原始池
- [ ] 已完成去重和标准化
- [ ] 重要关键词已标记主搜索意图
- [ ] 已补充业务 / 使用意图
- [ ] 相近关键词已形成主题组
- [ ] 每个重要主题组已有主要承接页面
- [ ] 已记录页面状态：已有 / 新建 / 更新 / 合并 / 重构
- [ ] 关键词数据注明来源和日期
- [ ] 重要判断标记可信程度
- [ ] 已检查关键词内耗
- [ ] 已形成第一批页面优先级

完成后：

- 新站、网站改版或重要产品体系项目，先进入 [网站架构与内容体系设计](../03-architecture/site-architecture.md)，把页面映射组织成完整网站。
- 已经拥有稳定网站架构、只准备制作某个具体页面时，可以直接进入 [搜索结果与竞争内容研究](serp-research.md)。

## 17. 本模块的核心原则

关键词研究始终围绕下面这条链路：

```text
用户搜索什么
↓
为什么搜索
↓
哪些查询属于同一个问题
```
