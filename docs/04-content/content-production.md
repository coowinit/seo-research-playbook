# 内容规划、写作与可信度审核

本文件负责把前期研究结果转化为可以正式发布的内容。核心原则不是“尽快写完”，而是确保每一个重要结论都知道 **为什么写、依据是什么、谁负责确认、发布前是否已经核验**。

本阶段的标准流程：

```text
搜索结果研究
↓
确认页面方案
↓
制作内容简报
↓
建立结论与证据清单
↓
确认文章结构
↓
完成初稿
↓
事实核验
↓
专业审核
↓
页面 SEO 与可读性审核
↓
最终放行
```

---

## 1. 进入本阶段前必须具备的资料

开始写作前，至少应具备：

- 明确的目标市场、语言和目标用户
- 已确认的主搜索意图与业务 / 使用意图
- 已完成的关键词到页面映射
- 已完成的搜索结果与竞争内容研究
- 已确定的用户核心问题和内容缺口
- 已识别的重要结论、争议点与高风险表述
- 企业可提供的产品资料、测试、案例或技术人员支持范围

如果这些信息还不明确，不建议立即进入正文写作。

---

## 2. 内容简报：把研究变成写作任务

内容简报不是文章大纲的同义词，而是“研究阶段”和“写作阶段”之间的正式交接文件。

至少应包含：

- 页面目标
- 主关键词与相关搜索需求
- 目标市场与读者
- 搜索意图与用户决策阶段
- 页面类型与建议网址
- 核心答案
- SEO 标题、H1 和 Meta Description 草案
- 主要 H2 / H3 结构
- 每个章节要解决的用户问题
- 必须使用的证据和企业资料
- 不能直接下结论的高风险内容
- 图片、表格和第一手资料计划
- 内部链接与行动引导
- 写作者、资料负责人和技术审核人员

使用：`templates/04-content/content-brief.md`。

### 内容简报的放行标准

满足以下条件后再进入写作：

- 页面要解决的问题已经明确
- 文章主要结论已经基本确定
- 章节结构与搜索意图一致
- 重要结论知道需要什么证据
- 缺失资料已经明确标记
- 不会因为缺少资料而逼迫写作者“补全事实”

---

## 3. 结论与证据清单

写作前先区分“可以直接写的内容”和“必须核验后才能写的内容”。

建议把文章中的重要陈述分为五类：

| 类型 | 例子 | 发布要求 |
|---|---|---|
| 通用事实 | 材料基础定义、公开标准 | 使用可靠来源核验 |
| 企业事实 | 产品组成、规格、产能、认证 | 必须使用企业最新版资料 |
| 性能结论 | 防滑、耐候、阻燃、吸水 | 必须对应明确测试方法、型号和适用范围 |
| 经验判断 | 某类场景更适合某种方案 | 说明条件、依据和限制 |
| 推测 / 营销表达 | “更环保”“寿命更长” | 不能伪装成事实；证据不足时删除或改写 |

### 推荐记录字段

| 结论 | 类型 | 需要的证据 | 资料来源 | 负责人 | 状态 | 最终处理 |
|---|---|---|---|---|---|---|
|  |  |  |  |  | 待补 / 已核验 | 采用 / 限定 / 删除 |

### 核心原则

> 研究阶段没有找到依据，不等于写作阶段可以让 AI 自动补出依据。

任何涉及以下内容的结论都应提高核验级别：

- 价格与成本
- 使用寿命
- 质保
- 防火
- 防滑
- 吸水 / 防水
- 环保与回收材料
- 认证与法规
- 安装参数
- 结构承载
- 化学成分
- 健康与安全

## 4. 文章结构：围绕用户决策，不围绕关键词数量

文章结构应来自三个来源：

1. 搜索结果中反复出现的核心用户问题
2. 竞争内容仍未解决的内容缺口
3. 企业能够提供的真实专业证据

不要因为某个相关关键词有搜索量，就强行增加一个独立章节。

### 标题层级

- 页面应有一个清晰、突出的主要标题，通常使用 H1；避免多个同等突出的重复主标题。
- 每个 H2 应解决一个明确问题或决策维度。
- H3 用于拆解 H2，不用于堆叠关键词。
- 标题顺序应帮助用户完成理解和决策。

### 开头

开头优先完成三件事：

1. 直接回答核心问题。
2. 说明最重要的条件或例外。
3. 告诉用户本文将如何帮助他做决定。

不要求机械限制在某个词数内，但不应使用大段无信息价值的铺垫。

### 预计内容范围

可以根据主题复杂度估算内容范围，但它只是：

- 工作量参考
- 章节覆盖参考
- 编辑排期参考

不是排名目标，也不应为了达到某个字数添加重复内容。

## 5. 初稿写作原则

### 先准确，再完整，再优化表达

推荐顺序：

```text
事实和逻辑正确
↓
用户问题完整
↓
表达清晰
↓
关键词自然
↓
转化衔接自然
```

不要反过来先追求“SEO 味道”。

### 内容表达

优先采用：

- 短段落
- 明确的小标题
- 真正适合比较的信息表格
- 真正适合操作的有序步骤
- 必要的条件说明
- 适用范围和限制
- 对反方观点的合理解释

### 关键词使用

页面主题应在 SEO 标题、H1、网址和正文中保持清晰一致。

可以自然使用：

- 主关键词
- 同义表达
- 相关概念
- 用户真实问题表达

不设置关键词密度，也不要求每个章节重复精确匹配词。

### 行动引导

行动引导应匹配用户当前阶段。例如比较型文章更适合：

- 查看产品系列
- 下载规格资料
- 查看测试文件
- 申请样品
- 联系项目顾问

而不是在每个章节反复要求“立即询价”。

## 6. AI 辅助写作的边界

AI 在本阶段主要负责整理、起草、改写和检查，不负责创造产品事实、测试结果、认证、质保、价格、法规结论或项目经历。

写作时至少遵守三条规则：

1. 先提供已经核验的研究资料和企业资料，再要求 AI 起草。
2. 无法确认的事实进入“待核验”状态，不允许自动补全。
3. 最终发布仍需人工事实核验和必要的专业审核。

关键词研究、竞争分析、内容简报、事实审核和发布后复盘中的完整 AI 使用规范，统一参见 [AI 辅助 SEO 研究与内容生产](ai-assisted-seo.md)。

## 7. 事实核验

初稿完成后，不要直接进入“润色”，先做事实核验。

建议逐条检查：

### 数据

- 是否注明数据对应的市场和时间？
- 是否区分材料价格和项目总成本？
- 是否避免使用已经过期的价格或政策？

### 产品性能

- 是否明确产品型号或结构？
- 是否明确测试方法？
- 是否把实验室结果扩展成了无限场景承诺？

### 质保与寿命

- 是否区分质保期与实际使用寿命？
- 是否说明质保条件和排除项？

### 标准与认证

- 是否引用正确版本？
- 是否确认标准适用国家、产品和使用场景？
- 是否把“通过某项测试”错误写成“满足所有法规要求”？

### 来源

优先级通常为：

```text
原始标准 / 政府 / 认证机构 / 原始测试
↓
企业官方技术资料
↓
行业协会和专业机构
↓
高质量专业媒体
↓
普通媒体 / 社区经验
```

来源越弱，结论越应该保守。

## 8. 高风险表述处理

以下绝对化表达需要特别谨慎：

- waterproof
- fireproof
- maintenance-free
- slip-proof
- scratch-proof
- fade-proof
- eco-friendly
- zero maintenance
- lasts 30 years / 50 years

优先改成能够说明条件的表达，例如：

- `water-resistant`
- `low-maintenance`
- `tested for specified fire performance`
- `covered by a 25-year limited residential warranty`

不要把营销方便放在事实准确性之前。

---

## 9. 专业审核

专业审核不是简单检查语法，而是确认“文章是否有资格代表企业发布”。

建议由对应人员审核：

| 内容 | 建议审核人员 |
|---|---|
| 产品结构与规格 | 产品 / 技术人员 |
| 安装参数 | 技术 / 安装人员 |
| 检测与认证 | 质量 / 技术人员 |
| 质保 | 产品 / 法务 / 业务负责人 |
| 企业能力 | 业务 / 运营负责人 |
| 项目案例 | 项目负责人 |
| SEO 与页面结构 | SEO / 网站负责人 |

### 审核结果统一分为

- **通过**：可以直接发布。
- **限定后通过**：增加条件、范围或免责声明后发布。
- **待补资料**：不能发布相关结论。
- **删除**：证据不足或不适合公开。

## 10. 内容可信度与 E-E-A-T 自检

E-E-A-T 不作为机械打分公式，而用于检查内容是否值得用户信任。

### 经验

- 是否有真实项目、安装、制造、测试或使用经验？
- 是否加入企业真正知道、竞争页面不容易复制的信息？

### 专业性

- 是否解释“为什么”？
- 是否说明条件、差异和例外？
- 是否避免把复杂问题压缩成绝对结论？

### 权威性

- 是否有明确作者或技术审核角色？
- 是否链接真正相关的技术资料和可靠来源？

### 可信度

- 是否注明发布日期和更新时间？
- 是否说明限制？
- 是否区分事实、经验判断和营销表达？
- 是否能够追溯重要结论的来源？

其中应始终优先保证 **可信度**。

---

## 11. 页面 SEO 与可读性审核

事实和专业审核通过后，再完成页面层优化：

- SEO 标题与 H1 是否准确反映正文？
- Meta Description 是否准确且具有点击价值？
- 网址是否简洁稳定？
- 标题层级是否清晰？
- 图片说明和 Alt 是否准确？
- 内部链接是否真正帮助用户继续理解？
- 行动引导是否符合用户决策阶段？
- 是否存在明显重复、空话和关键词堆砌？
- 手机端表格、图片和长段落是否易读？

页面 SEO 不应反过来破坏内容准确性。

---

## 12. 最终放行门

文章进入发布环节前，至少满足：

- [ ] 核心搜索意图没有偏离
- [ ] 重要结论有证据或明确依据
- [ ] 企业事实使用最新版公司资料
- [ ] 所有高风险表述已经核验
- [ ] 没有未处理的关键“待确认”内容
- [ ] 技术 / 专业审核已经完成
- [ ] 页面 SEO 与可读性已经完成
- [ ] 作者、审核、更新时间等必要信息已经确定
- [ ] 行动引导和内部链接已经确认

如仍存在关键事实缺口，宁可延后对应结论，也不要用推测填补。
