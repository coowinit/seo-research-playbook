# SEO 常用术语表

本仓库以中文表达为主。产品关键词、工具名、标准缩写和部分行业通用术语在有必要时保留英文。

为避免单张超长 Markdown 表格在 GitHub 中因空行或后续维护而断裂，术语按主题分组整理。

## 1. SEO 研究与关键词

| 推荐写法 | 英文 / 缩写 | 说明 |
|---|---|---|
| 母关键词 | Seed Keyword | 能代表核心产品或主题，并用于向外扩展的起点关键词 |
| 关键词原始池 | Keyword Pool | 尚未完成清洗、聚类和页面判断的初始关键词集合 |
| 搜索意图 | Search Intent | 用户进行一次搜索时真正想完成的事情 |
| 主搜索意图 | — | 本仓库分为信息型、商业比较型、交易型和导航型 |
| 业务 / 使用意图 | — | 用户围绕产品具体解决的问题，如 B2B采购、产品比较、安装施工、应用场景等 |
| 关键词主题组 | Keyword Cluster | 可以由同一页面完整承接的一组相关搜索需求 |
| 关键词到页面映射 | Keyword-to-Page Mapping | 明确每个主题由哪个页面类型、网址和转化目标承接 |
| 关键词内耗 | Keyword Cannibalization | 多个页面争夺同一核心搜索需求，且页面职责没有清晰区分 |
| 竞争网站研究 | Competitor Site Research | 从网站级观察竞争者的业务定位、产品体系、页面类型、内容结构、内部链接、技术基础、外部引用和转化路径 |
| 直接观察事实 | Direct Observation | 可以从公开网站、页面、代码或公开资料直接确认的信息，并记录来源和日期 |
| 第三方估算 | Third-party Estimate | Ahrefs、Semrush、Similarweb 等工具根据自身数据库和模型估算的流量、关键词、外链等数据，不等同于对方后台真实数据 |
| 页面类型矩阵 | Page Type Matrix | 按产品分类页、单品页、比较页、指南页、工具页、资料页、案例页等职责整理竞争网站页面体系 |
| 引荐域名 | Referring Domain | 包含至少一个指向目标网站或页面链接的外部域名；不同工具的统计和去重方法可能不同 |
| 品牌引用 | Brand Mention | 外部网站、媒体、协会、经销商或社区对品牌的提及，可能带链接，也可能不带链接 |
| 网站枢纽页 | Hub Page | 在网站结构中连接多个相关页面、承担主题或类别导航作用的重要页面 |
| DR / DA / Authority Score | — | 第三方 SEO 工具自己的站点评价指标，只用于对应工具内的相对比较，不是 Google 官方排名分数 |
| 搜索结果页面 | SERP | 搜索引擎返回的结果页面；必要时保留 SERP 缩写 |
| 搜索结果快照 | SERP Snapshot | 记录某个市场、设备和日期下搜索结果整体结构的研究记录，不代表长期固定排名 |
| 代表性竞争页面 | — | 为覆盖主要页面类型、来源类型和内容模式而选择的研究样本，不机械等同于前 10 名 |
| 结论与证据矩阵 | — | 把关键结论、来源一致性、证据强度和采用方式放在同一表中核验 |
| 来源偏向 | Source Bias | 判断品牌、零售商、媒体、行业组织或社区内容可能存在的利益关系和立场 |
| 内容缺口 | Content Gap | 用户在现有搜索结果中仍未获得清晰、准确或可执行答案的部分 |
| 可信程度 | Confidence | 对关键词意图、数据或研究结论可靠程度的标记 |
| Google Keyword Planner | — | Google Ads 中的关键词数据工具，保留产品名称 |

## 2. 内容生产与页面 SEO

| 推荐写法 | 英文 / 缩写 | 说明 |
|---|---|---|
| 内容简报 | Content Brief | 研究完成后交给写作者或内容团队的正式写作要求 |
| 结论与证据清单 | — | 在写作前记录重要结论、证据需求、资料来源、负责人、状态和最终处理方式 |
| 事实核验 | Fact Checking | 对数据、产品性能、标准、认证、质保和企业事实逐项确认 |
| 专业审核 | Technical / Expert Review | 由产品、技术、质量、安装或其他相关负责人确认专业内容是否可以公开发布 |
| 最终放行门 | Publication Gate | 只有关键事实、专业审核、页面 SEO 和技术条件满足后才进入发布 |
| 高风险表述 | — | 容易形成绝对承诺或超出证据边界的性能、寿命、环保、认证等表达 |
| 页面 SEO | On-page SEO | 页面职责、SEO 标题、正文结构、网址、图片、内部链接、面包屑与转化入口等页面层优化 |
| SEO 标题 | Title Element / `<title>` | HTML `<title>` 元素中的页面标题，是 Google 生成搜索结果标题链接的重要来源之一 |
| 标题链接 | Title Link | Google 搜索结果中可点击的页面标题，可能由 `<title>`、主标题、H1、页面显著文本和链接文字等多种来源生成 |
| Meta Description | — | 页面 `<meta name="description">` 中的摘要候选；Google 也可能根据具体查询从正文生成搜索摘要 |
| 主标题 | Main Heading | 页面最主要、最突出的可见标题，通常使用 H1；重点是清晰表达页面主题，不把 H1 数量当机械排名规则 |
| 锚文本 | Anchor Text | 链接中可见、可点击的文字，用于帮助用户和搜索引擎理解目标页面 |
| 面包屑 | Breadcrumb | 表达当前页面在网站层级中位置的导航路径；结构化数据实现细节属于技术 SEO |
| Alt | Alternative Text | 图片替代文本，用于描述图片内容和作用；应结合图片上下文和无障碍需求，不用于关键词堆砌 |
| 内部链接 | Internal Linking | 网站内部页面之间的链接关系 |
| 行动引导 | CTA | 引导用户查看产品、下载资料、申请样品、询价等下一步动作 |
| 用户决策阶段 | Funnel Stage | 用户处于了解、比较、决策或购买后的哪个阶段 |
| E-E-A-T | — | 经验、专业性、权威性与可信度的质量理解框架 |
| AI 辅助研究 | AI-assisted Research | 使用 AI 对已提供资料进行整理、归纳、扩展和初步分析，但不把 AI 作为关键事实来源 |
| 可信状态 | — | 对 AI 或研究输出标记为“已确认、有依据的判断、待核验、不采用”，避免判断在后续流程中被误当成事实 |
| 待核验清单 | — | 集中记录尚缺少真实数据、企业资料或专业确认的问题，并跟踪负责人、状态与最终结论 |
| 证据边界 | — | 明确某个结论现有证据能够支持到什么程度，以及哪些表达超出了已有资料 |

## 3. 技术 SEO

| 推荐写法 | 英文 / 缩写 | 说明 |
|---|---|---|
| 技术 SEO | Technical SEO | 抓取、索引、规范网址、站点地图、性能、结构化数据等技术层优化 |
| 抓取 | Crawling | 搜索引擎机器人发现并请求网址、HTML 和相关资源的过程 |
| 索引 | Indexing | 搜索引擎处理页面并决定是否把页面加入搜索索引的过程；允许索引不等于保证收录 |
| robots.txt | — | 位于站点根目录、主要用于控制抓取路径的协议文件，不等同于 noindex |
| noindex | — | robots Meta 或响应头中的索引控制指令，用于告诉支持该指令的搜索引擎不要把页面保留在搜索结果中 |
| X-Robots-Tag | — | 通过 HTTP 响应头控制索引 / 展示行为，常用于 PDF 等非 HTML 资源 |
| XML Sitemap | — | 向搜索引擎提供希望发现和处理的规范网址清单；不保证页面一定被索引 |
| HTTP 状态码 | HTTP Status Code | 服务器对网址请求返回的状态，例如 200、301、404、410、503 |
| 永久重定向 | Permanent Redirect | 表示网址已长期迁移到新位置，常见 301 / 308 |
| 临时重定向 | Temporary Redirect | 表示网址暂时跳转到其他位置，常见 302 / 307 |
| Soft 404 | — | 页面实际像不存在或内容为空，但服务器却返回 200 等成功状态的情况 |
| 渲染 | Rendering | 搜索引擎执行页面资源和 JavaScript 后形成可处理页面内容的过程 |
| JSON-LD | — | 常用结构化数据格式之一，适合将机器可读数据与页面展示代码相对独立维护 |
| LCP | Largest Contentful Paint | Core Web Vitals 指标之一，衡量主要内容加载表现 |
| INP | Interaction to Next Paint | Core Web Vitals 指标之一，衡量页面交互响应表现 |
| CLS | Cumulative Layout Shift | Core Web Vitals 指标之一，衡量页面视觉稳定性 |
| hreflang | — | 用于表达不同语言 / 地区页面对应关系的国际化标记；只在真实多语言 / 多地区架构中使用 |
| Canonical | — | 规范网址标记，属于标准技术术语，保留英文更便于与代码对应 |
| Schema | — | 结构化数据相关标准术语，仓库中可写作“结构化数据（Schema）” |
| Core Web Vitals | — | Google 网页核心指标，保留官方名称 |

## 4. 建筑与外墙专业术语

| 推荐写法 | 英文 / 缩写 | 说明 |
|---|---|---|
| 外墙覆盖层 | Exterior Wall Cladding / Exterior Wall Covering | 建筑外墙最外侧的覆盖材料或系统；具体法规用词应以当地规范为准 |
| 墙体系统 | Wall Assembly | 包含基层、防水 / 防风雨层、龙骨或空腔、保温、外饰面和节点等完整构造，不等同于单块 Cladding 板材 |
| 通风雨幕 | Rainscreen | 通过外饰面、排水 / 通风空腔和后部防护层共同管理雨水与湿气的外墙构造概念 |
| 防水 / 防风雨层 | Water-Resistive Barrier, WRB | 外墙系统中用于管理进入墙体水分的防护层；美国资料中常见 WRB 缩写 |
| 龙骨 / 垫条 | Battens / Furring Strips | Cladding 背后的支撑与固定构件，也常用于形成排水或通风空腔；具体材料和间距必须按系统设计 |

## 5. 网站架构与内容体系

| 推荐写法 | 英文 / 缩写 | 说明 |
|---|---|---|
| 网站架构 | Site Architecture | 网站中页面类型、产品与内容层级、导航、内部链接、URL、资料和转化路径形成的整体关系，不等同于菜单或文件夹结构 |
| 页面职责 | Page Role | 某个页面在网站中主要解决的用户任务、搜索需求和业务任务 |
| 内容体系 | Content System | 按用户任务组织指南、比较、安装、维护、技术资料、FAQ、工具、案例等内容资产的方式 |
| 导航层级 | Navigation Hierarchy | 用户通过主导航、二级导航等界面看到的网站层级关系 |
| 分类体系 | Taxonomy | 用于组织产品、内容、案例或资料的分类规则；应服务真实内容关系，不为了 SEO 制造大量空分类 |
| 筛选导航 | Faceted Navigation | 根据颜色、尺寸、表面、应用等属性组合筛选内容或产品的导航方式，可能产生大量参数 URL |
| 分页 | Pagination | 把长列表拆成多个可访问页面的方式；需要保证后续内容仍可被链接和抓取发现 |
| 孤立页面 | Orphan Page | 没有正常内部链接指向、主要依赖 Sitemap 或直接 URL 才能发现的页面 |
| 点击深度 | Click Depth | 从某个入口页面通过内部链接到达目标页面所需的链接层级；用于辅助判断页面是否容易被发现，不采用固定三次点击公式 |
| URL 迁移映射 | URL Migration Mapping | 网站改版时记录旧 URL、目标新 URL、保留 / 合并 / 重定向等动作的映射表 |
| 技术资料说明页 | — | 为 PDF、测试报告、安装文件等提供产品归属、版本、适用范围和下载入口的 HTML 页面 |

## 6. Search Console 与数据分析

| 推荐写法 | 英文 / 缩写 | 说明 |
|---|---|---|
| Google Search Console | — | Google 官方站点搜索表现与索引工具，保留产品名称 |
| 搜索表现 | Search Performance | 页面在 Google 搜索中的展示、点击、点击率、查询词和平均排名等数据表现 |
| 点击率 | CTR | 点击次数除以展示次数；需要结合排名、查询意图和搜索结果环境判断 |
| 平均排名 | Average Position | Search Console 中搜索结果最高位置的平均值，不代表固定排名 |
| 生成式 AI 搜索表现 | Generative AI Performance | Search Console 中用于观察 AI Overviews、AI Mode 等生成式 AI 搜索曝光的报告 |
| 网站级 Search Console 分析 | — | 从全站、品牌 / 非品牌、页面组、页面、查询词、国家、设备和时间维度诊断网站真实搜索表现 |
| 品牌词 | Branded Query | 包含企业、品牌或明确品牌产品名称的搜索查询；具体分类以项目品牌规则为准 |
| 非品牌词 | Non-branded Query | 不包含明确品牌名称、更多反映通用产品或问题需求的查询 |
| 页面组 | Page Group | 按 URL 目录、页面类型、产品类别或业务职责组合的一组页面，用于网站级表现分析 |
| 查询词 × 页面 | Query-to-Page Analysis | 选择某个查询后查看哪些页面获得展示，用于判断页面职责、搜索意图和潜在内耗 |
| 初步数据 | Preliminary Data | Search Console 最新时间段仍可能继续更新的数据，不适合据此立即做重大修改 |
| 匿名查询 | Anonymized Query | 因隐私保护不会显示在查询表中的搜索词，其点击 / 展示仍可能计入总体数据 |
| 数据异常 | Data Anomaly | Search Console 统计、记录或产品变化造成的报告异常，需要先与真实网站问题区分 |
| Search Console API | — | 用于程序化读取 Search Console 搜索表现数据的官方接口，适合自动报表和历史保存 |
| 批量数据导出 | Bulk Data Export | 将 Search Console 搜索表现持续导出到 BigQuery 的官方能力，适合大型网站和长期数据分析 |

## 7. 内容资产与治理

| 推荐写法 | 英文 / 缩写 | 说明 |
|---|---|---|
| 内容维护 | Content Maintenance | 页面发布后的保持、微调、更新、扩展、合并、重构或移除 |
| 内容衰退 | Content Decay | 页面表现随时间下降的现象；需要先判断搜索需求、竞争、内容准确性等原因，不作为自动更新结论 |
| 内容资产 | Content Asset | 网站中具有用户、搜索、业务、技术支持、品牌或历史价值的页面、PDF、案例、工具等可维护内容 |
| 历史内容治理 | Content Governance | 从整站角度盘点并决定内容保持、更新、扩展、合并、重构、移除及技术迁移的长期维护机制 |
| 内容资产清单 | Content Inventory | 记录 URL、页面职责、页面类型、产品状态、搜索表现、业务价值、技术状态和治理动作的全站清单 |
| 内容合并 | Content Consolidation | 将多个承担相同主要用户需求的页面整合为一个职责更清楚的目标页面，并处理旧 URL 和链接关系 |
| 已停产页面 | Discontinued Page | 产品已经停止销售但可能仍保留售后、安装、Warranty、历史项目或外部引用价值的页面 |
| 归档内容 | Archived Content | 因历史、法规、客户支持等原因继续保留，但已明确不是当前版本或当前主推内容的资料 |
| Search Console Removals | — | Search Console 中用于临时从 Google 搜索结果隐藏网址的工具，不替代网站本身的永久移除、noindex、404 / 410 或访问控制 |
| 治理优先级 | Governance Priority | 按事实风险、业务影响、搜索价值和影响范围把历史内容问题划分为 P0—P3 等处理优先级 |

## 使用原则

- 正文能准确用中文表达时，优先使用中文。
- 工具、产品、标准、代码属性和真实产品关键词不强行翻译。
- 首次出现的重要缩写可使用“中文名称（英文缩写）”，后文再使用缩写。
- 不为了显得专业而堆叠英文术语。
