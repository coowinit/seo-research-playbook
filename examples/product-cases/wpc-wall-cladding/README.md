# WPC Wall Cladding SEO 研究案例

本案例用于验证 v1.1.0 建立的 SEO 研究与内容生产方法，是否能够从 **Composite Decking** 扩展到另一类 WPC 建材产品。

第二案例选择母关键词 `wpc wall cladding`，并以 `wpc wall cladding vs wood cladding` 作为完整文章主题。

与 Decking 相比，Wall Cladding 除了材料性能，还会涉及墙体构造、通风排水、基层、固定系统、防火性能和当地建筑规范，因此更适合检验方法在技术约束更强的产品中是否仍然成立。

## 本案例重点验证什么

### 1. 同一套关键词研究流程能否跨产品复用

答案是可以，但扩展维度必须随产品变化。

Decking 更容易出现：

- 表面温度
- 防滑
- 龙骨间距
- 泳池应用

Wall Cladding 则自然增加：

- 墙体系统
- 通风与排水
- 防水层 / 防水屏障
- 固定方式
- 立面方向
- 防火与法规
- 风荷载与项目适用性

### 2. 页面映射不能只按“关键词长相”判断

例如：

- `wpc wall cladding`
- `wpc wall cladding manufacturer`
- `wpc wall cladding installation`
- `wpc wall cladding fire rating`

虽然共享核心词，但用户目标完全不同，应由不同页面承担。

### 3. 技术约束越强，证据边界越重要

Cladding 文章不能仅讨论“耐候、低维护、好看”。正式项目还要确认：

- 所选产品到底属于什么材料体系
- 是否用于 exterior wall covering / rainscreen
- 是否需要通风空腔和排水路径
- 产品与墙体系统的安装条件
- 防火测试到底对应材料、板材还是完整墙体系统
- 当地建筑规范是否允许该用法

因此本案例尤其强调：

> **材料性能不能自动等同于完整墙体系统性能。**

## 使用说明

案例中的公开页面、产品数据和搜索结果会变化。正式项目必须重新检查目标市场搜索结果，并用企业自身最新版产品规格、安装手册、测试报告、认证和项目资料替换通用内容。

本案例同样不填写虚构搜索量。真实项目应使用明确的数据工具补充，并记录数据来源和日期。
